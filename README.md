# 【书刊28】 金融法的制度源流

> 专业·金融法

## 关于本书

金融法的规则不是从法条里长出来的，是从金融危机里长出来的。追溯现代金融法制度源流：威尼斯契约公证人、阿姆斯特丹交易所、南海泡沫催生泡沫法案、大萧条催生证券法、2008催生宏观审慎。按危机—立法—失效—再立法的循环组织：每次立法都是对上次危机的回应，每种监管都在孕育下一种规避。
